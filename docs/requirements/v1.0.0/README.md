## 一句话定位
面向多环境 Web 系统的 Chrome 账号管理与登录填充插件（Manifest V3）。默认使用 Chrome 本地明文存储，MinIO 为可选同步通道。定位为「**多环境登录助手**」，**非加密保险箱、非 Web 后台系统**。

## 项目背景
用户需要在多个网站、多个环境、多组账号之间频繁登录。前身方案以油猴脚本在登录页识别环境、展示账号浮窗、复制 / 填充、并与 MinIO 同步，已验证核心价值。本项目将其重构为独立、可上架 Chrome 应用商店的插件，并以本地完整配置为默认数据源，MinIO 仅作可选同步。

## 项目目标
- 独立 Chrome MV3 插件，不依赖任何用户脚本运行环境，具备上架条件。
- 以单一「完整配置 JSON」为数据中心，覆盖：全局设置、项目分组、字段模板、项目 / 环境 / 字段 / 账号、同步配置。
- 登录页浮窗 + 输入框账号选择器 + 自动填充默认账号。
- 配置管理页提供可视化增删改查、完整 JSON 查看 / 编辑、导入导出。
- 可选 MinIO 同步（远程↔本地，按稳定标识合并 / 覆盖）。
- 三套外观主题、字号、动效全局可调，并同步到配置页 / popup / 登录页浮窗。

## 需求范围（v1.0.0 实际覆盖）
1. Chrome 插件独立运行、图标 popup、配置管理页（独立标签页）。
2. 登录页识别（host + path）、账号浮窗、复制、敏感字段显隐、自动填充、输入框账号选择器。
3. 登录页 / popup 账号可视化增删改查。
4. 配置管理页七大模块：全局配置、项目分组、项目管理、字段配置模板、账号管理、配置导入导出、数据同步。
5. 完整配置 JSON 查看与编辑、严格校验。
6. 本地完整配置（Chrome storage.local）默认可用。
7. 可选 MinIO 同步（直连单个 JSON 对象）。
8. JSON 导入 / 导出（导出支持按项目子集、是否含 MinIO、是否含主题）。
9. 字段统一模型与列宽自适应。
10. 明文存储前提下的默认隐藏、风险提示。
11. 登录页 `/login` CryptoJS 解密容错（page-guard）。

## 明确不要求
- 不兼容旧油猴脚本的 MinIO 分散 JSON 格式，不读写 `{projectId}-{envId}.json`。
- 本版本不引入密码加密存储，按明文处理（默认隐藏 + 风险提示）。
- MinIO 不使用官方 SDK 签名鉴权，采用用户自管的 HTTP 对象直连（见数据需求与设计）。

## 关键术语
- **完整配置 JSON（AppConfig）**：包含全局设置、项目分组、字段模板、项目、同步配置、元信息的单个对象，是唯一数据中心。
- **项目（Project）**：一个网站 / 业务系统，含字段定义、环境列表、所属分组、登录页弹窗位置。
- **项目分组（ProjectGroup）**：项目的归类，含稳定 `code`、名称、描述；必含 `default` 默认分组。
- **字段模板（FieldTemplate）**：可复用的一组字段定义，新建项目时可一键套用。
- **环境（Env）**：项目下一个可登录入口，含 host 列表、path 关键字、重试延迟、账号列表。
- **字段（Field）**：浮窗 / 配置页中的列定义，分 `input`（参与填充）与 `display`（仅展示）。
- **账号记录（Account）**：某项目环境下一组字段值，含稳定 `id`、`values`、`isDefault`、`updatedAt`。
- **本地配置 / 云端配置**：分别保存在 Chrome `storage.local` 与 MinIO 对象中的完整配置 JSON。
- **增量合并**：按稳定标识合并新增 / 更新，同 id 以来源端覆盖，不整体清空目标端。

## 交付边界
可安装的 Chrome MV3 插件工程；无 MinIO 时完整可用；配置 MinIO 后可由用户主动触发远程↔本地同步。需求经人工确认后进入 / 更新技术设计。
